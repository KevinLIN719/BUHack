# Surface transitions · frontend polish

Implemented 2026-11-13 in surface-motion.js. This module supplies small, finite transitions for the existing component guide. It does not add data processing, backend behavior or a new product journey, and does not replace the concept, message bubble, paper pull or completion effects.

## API and ownership

window.PolicySurfaceMotion.mount(root=document) is idempotent for a Document or Element and returns:

```js
const surface = PolicySurfaceMotion.mount(document);
surface.enter(copyNode);                  // Opacity only by default.
surface.visibility(panel, true);          // hidden becomes false immediately.
surface.visibility(panel, false);         // hidden becomes true immediately.
surface.cancel(panel);                    // Also settles descendant operations.
surface.destroy();                       // Final page-level cleanup.
```

enter and visibility return promises that resolve after finish or cancellation. cancel/destroy are synchronous and preserve the latest committed native state. Calls after destroy are inert. Repeated mount on the same root returns the existing controller; a fresh mount after destroy is supported.

Use one shared document controller in the guide. Individual components borrow it and cancel their own surfaces when removed; only the page owner should destroy that document controller. Element-root removal destroys its scoped controller. Light DOM is the intended scope; ShadowRoot is not accepted.

enter accepts optional opacity, duration and distance. Defaults are opacity .35 to the underlying opacity, 240ms and distance zero. It preserves all original DOM identities and input values. An explicit small distance can be used for an ordinary reading block; direct input/textarea/select/button/contenteditable targets always remain opacity-only, with no height or transform changes to their hit area.

visibility is intended for ordinary flow or grid surfaces such as the chat panel. Opening uses a short height/opacity transition. Closing immediately hides the real node, inserts a temporary visual snapshot and flow slot, then reduces that slot. Reversing samples the current slot/live height before removing the previous operation. Newer author-owned inline styles are preserved when temporary styles are restored. These helpers do not provide arbitrary fixed/sticky modal choreography.

The single timing source is PolicySurfaceMotion.timings in the JavaScript: enter 240ms, visibility 280ms, disclosure 300ms, cubic-bezier(.22,1,.36,1). No stylesheet, animation service or asset is required.

## Native disclosures

One delegated click listener handles direct summaries, including the marker/arrow and the click generated by native Enter/Space activation. Nested links, buttons, inputs and modified clicks retain their native actions. No key event or synthetic click is generated by this helper.

User toggles commit details.open synchronously. The real details height transitions between its current and final size; closing uses a fixed visual snapshot of the body because native closed details stops painting that content. Rapid reverse starts from the measured live height. The outgoing snapshot is capped at the previously visible bottom, so closing a partly opened disclosure cannot expose its hidden tail. Body element nodes remain in their original locations and retain their events and values. The guide's disclosures all contain element bodies; bare text-only disclosure bodies receive height settling without a separate text snapshot.

Programmatically assigning details.open remains native. It does not cause automatic animation; if it changes an already animating disclosure, the old animation settles without overriding that latest state. Initial open sections do not autoplay.

## Snapshot and cleanup contract

- Snapshots are aria-hidden and inert, with pointer events disabled and native focusable descendants removed from the tab order. Automatic liquid-control mounting is excluded at the snapshot root.
- IDs, roles, aria references, event attributes, form/name/href/for/autofocus/contenteditable attributes and behavioral data hooks are removed. Current input/textarea values, checkbox/indeterminate state, select state and scroll positions are copied.
- Only the original classes and selected visual data traits are retained: marker/priority, selected/state/token and the liquid skin's presentation state. This keeps current component CSS accurate. A class-only document query can therefore see a short-lived visual clone; use stable behavioral data hooks or cached references for real component operations. The guide's chat and workbench controllers already use their cached real nodes. Snapshotting custom SVG definitions whose IDs are essential is outside the current guide's needs.
- Every operation owns only its own WAAPI animations and exact temporary styles. Completing/cancelling removes its snapshots/slots, restores owned style values, clears its watchdog and consumes cancelled animation promises.
- Reduced motion, forced colours, hidden documents, resize, removal and hidden/inert ancestors settle to accurate final native states. Scrolling settles fixed disclosure snapshots so they cannot drift away from their source.
- No requestAnimationFrame loop or interval is created. The finite watchdog is cleared on normal finish/cancel. Missing WAAPI uses immediate native states.

Do not add height/transform entry on the same workbench geometry while a policy pull is being measured. Use enter with its default zero distance on the excerpt or reading list. The same rule avoids competing with existing message/completion/hero transform owners.
